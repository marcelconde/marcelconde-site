# Defeitos conhecidos

Última revisão: 2026-10-01. Não há defeito aberto reproduzível documentado neste repositório nesta data. Não trate uma funcionalidade ainda não implementada, nem uma validação externa pendente, como bug confirmado.

Para registrar um defeito, descreva:

- ambiente (produção/Sandbox, navegador e página), sem dados pessoais ou secrets;
- passos mínimos para reproduzir;
- resultado observado e resultado esperado;
- ID interno de galeria/cobrança quando necessário, sem incluir credenciais;
- evidência da causa, correção e teste de regressão, se disponíveis.

O estado de funcionalidades e validações pendentes está em [`current-state.md`](current-state.md).
